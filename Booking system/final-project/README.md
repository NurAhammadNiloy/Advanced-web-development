# Booking System

Full-stack booking system for Task K1.

The project includes a React frontend, an Express API, and a PostgreSQL database running with Docker Compose.

## What Works

- User registration and login
- User profile update and password change
- Resource listing, creation, update, and deletion
- Resource reservations
- Reservation listing and cancellation
- PostgreSQL database initialization

## Run

```bash
docker compose up --build
```

Frontend: http://localhost:8080

API health check: http://localhost:3000/api/health
